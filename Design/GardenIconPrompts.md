# Garden finish: рисованные иконки

Созданы встроенным инструментом image_gen, с настоящей прозрачностью. Референсы пользователя использованы как направление стиля; изображения с нуля, без персонажей и нарядов.

Ресурсы проекта: `CurrentProject/Assets/Capybara67/Resources/GardenIcons/{leaf,mandarin,ball,brush}.png`.
Оригиналы 1254 × 1254 сохранены без редактирования. Unity импортирует каждый ресурс в 256 × 256, без mipmaps и Read/Write. Верхняя оценка RGBA32 для четырёх текстур: 1 MiB; это оценка памяти текстур, не замер всей игры.
