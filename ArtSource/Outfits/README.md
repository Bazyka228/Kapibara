# Цельные наряды

Решение пользователя от 16.10.2026: **сохраняем любые сочетания** головных уборов и одежды. Позже в этот же день число возрастов сокращено до пяти: бывшие 1, 2, 3, 6, 9. Старые PNG из девяти рисунков остаются исходниками; runtime-каталог использует только пять нужных областей. Новые листы рисовать сразу из пяти персонажей.
Каждый готовый вариант — самостоятельная иллюстрация всей капибары с обоими предметами,
на всех пяти возрастах. Сборка старых слоёв в PNG не считается новой иллюстрацией.

## Объём и учёт

`production.csv` содержит все 26 × 23 = 598 пар, включая пустые слоты: 2990 портретов
для классического окраса и обычной формы. `integrated` означает наличие готового PNG
и разметки всех пяти стадий в runtime-каталоге. `planned` означает, что рисунков пока нет.
Проверку Unity фиксировать отдельно в `validation.txt`, а не выводить её из статуса CSV.
Остальные 9 окрасов и 8 особых форм пока не перерисованы; эти варианты не входят в 2990.

Сгенерировать актуальный список из игрового гардероба и runtime-каталога:

```powershell
./ArtSource/Outfits/Update-ProductionManifest.ps1
```

## Добавление рисунка

1. Использовать встроенный imagegen. Один запрос — один полный лист из пяти стадий
   для конкретной пары вещей. Сохранять точный запрос в `*-prompt.txt`.
2. Проверить все позы, особенно лежащую первую стадию и сидящие четвёртую и пятую. Не допускать
   перекрытия соседних персонажей или обрезания головных уборов.
3. Скопировать выбранный PNG с настоящим alpha в `Assets/Capybara67/Resources/Outfits/`.
4. Разметить каждый силуэт и глаза в `Catalog.json`. `crop` — пиксели от левого верхнего
   угла, `frame` — размещение в игровом портрете 240×250. Размеры исходного атласа
   хранить явно. Отрицательный `eyes.w` означает уже закрытый глаз. Не деформировать
   глаз, слившийся с контуром морды. Рисунки могут немного сдвигаться: координаты
   исходного атласа нельзя слепо копировать.
5. `Measure-Atlas.ps1 -Path ... -Eyes` читает alpha-границы и отдельные тёмные детали.
   Он измеряет связные силуэты; для другого количества персонажей его параметры нужно
   проверить. Это анализ PNG, скрипт никогда не рисует и не изменяет изображение.
6. Запустить Unity-проверки через `Temp/Capy67-garden-capture` и `Temp/Capy67-idle-checks`.
   Просмотреть `Logs/GardenReview/combo-*.png` и кадры моргания. Обновить отчёт.

## Выбор в игре

Ключ содержит голову, одежду, окрас и особую форму. Примерка меняет только свой слот
в копии выбранных вещей. Готовый рисунок заменяет тело и оба аксессуара одновременно.
Дыхание двигает цельный наряд; моргание использует собственные координаты глаз каждого
рисунка. Эффекты вокруг героя продолжают работать. Для неперерисованных вариантов
сохраняется прежнее отображение обеих вещей. Одежда, покупки и прогресс не удаляются.

Текстуры загружаются только для показанных персонажей и примерок. Последний экземпляр
освобождает свой атлас; отложенное удаление старого UI учитывается счётчиком ссылок.
