# DOTween и реакции заботы

Подключена бесплатная DOTween 1.3.045 (официальный архив Demigiant, 12.10.2026).

- Источник: https://dotween.demigiant.com/downloads/DOTween_1_3_045.zip
- SHA-256 архива: 32EBA5C48520A541775D00CB396E18975B83587BA79175DBB878D753725BA5D9
- Документация: https://dotween.demigiant.com/documentation.php
- Лицензия: https://dotween.demigiant.com/license.php
- Исходный архив сохранён здесь; установленная библиотека — Assets/Plugins/Demigiant/DOTween. Файлы поставщика не менялись, readme.txt сохранён. Pro не нужен.

CapyTweenDriver обновляет только анимации этой игры через Tween.ManualUpdate. Он не вызывает глобальные DOTween.KillAll/PauseAll/ManualUpdate. При потере фокуса и паузе SDK время анимаций не идёт. При спокойном режиме анимации завершаются в конечном состоянии. Связь SetLink(KillOnDisable) очищает анимации закрытых объектов; отключение владельца также уничтожает его твины.

Применение: нажатие и отпускание кнопок с сохранением центра, плавное появление страниц, заполнение трёх шкал заботы. В сохранениях нет ссылок на твины. Экономика, покупки и награды не зависят от завершения анимации.

Дополнительно улучшены подсказки первой миски, подписи шкал, таймеры действий и сна. После заботы показывается фактическое изменение с учётом максимума 100, после еды — рост и сытость. Пузыри всплывают с разной задержкой, мяч возвращается, щётка делает три движения. Довольное моргание состоит из двух коротких закрытий глаз; контуры и одежда не деформируются. Кормление не перекрывает событие взросления.

Проверка: Compile-Staging.ps1, изолированный Unity integration в CapyIdleValidation. Специальные проверки охватывают центр кнопки, паузу SDK, спокойный режим, быстрые переключения меню, точность результата заботы, подсказки и размеры текста. Результаты текущего прогона — Verification/CareSystem. WebGL и реклама остаются приостановлены.

Установка в Second Project завершена через официальный DOTween Utility Panel. Включены UI, Audio и Sprites, отключены Physics/Physics2D. DOTweenSettings.asset сохранён; в проекте выставлены DOTWEEN, DOTWEEN_NOPHYSICS, DOTWEEN_NOPHYSICS2D. Публикация WebGL не выполнялась.

Официальный Setup удалил одноразовый DOTweenUpgradeManager из установленной папки. Полный архив сохранён в ArtSource; runtime и остальные файлы поставщика совпадают с оригиналом.
